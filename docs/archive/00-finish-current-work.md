# Phase 00 - Finish current work

## Goal
Reach a stable, tagged starting point before the rework begins. Do not mix unfinished work with this brief.

## Tasks
1. Finish the changes you are in the middle of, or bring them to a stable checkpoint. Anything unfinished goes on a written list for later (put it in docs/HANDOFF.md).
2. Run tools/check-quick.py and record what passes.
3. Commit and tag the result `baseline`.
4. Tell me what the baseline contains (version number, what changed since alpha 0.4.1).

## Ask me before
Dropping any in-progress feature instead of finishing it.

## Done when
`baseline` tag exists, the quick check result is recorded, and the unfinished list is written down.

## First reply
State what is in progress, what you can finish, and what you propose to park.
